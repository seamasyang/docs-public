## 4.2 向量数据库中的索引



> 向量数据库工作流程
>
> 1. 数据存储：高纬向量存入向量数据库
> 2. 索引构建：通过哈希，量化或图结构等技术为向量嵌入建立索引，以加速查询
> 3. 查询检索：接受查询请求后，向量数据库比较查询向量与索引中的向量，利用相似度度量方法确定最邻近向量
> 4. 检索后处理：对找到的最近邻结果进一步筛选或排序，以优化查询结果
>


#### 向量索引方式

FLAT，扁平索引。逐一比较所有向量

IVF，倒排文件索引(Inverted File Index)。通过将向量数据聚类来减少查询需要比较的向量数据

量化索引，通过压缩向量数据来减少存储空间和计算量。量化方法：标量量化SQ, 乘积量化PQ, 优化乘积量化OPQ

图索引，层次化可导航小世界图（Hierachical Navigable Small Word Grpah, HNSW）,专用于加速向量的ANN搜索。利用小世界网络的特点，通过构建一个多层图结构来实现对大规模向量数据集中的相似向量提供快速检索。 [es ref](https://www.elastic.co/search-labs/blog/hnsw-graph)

哈希技术，局部敏感哈希（Local Sensitive hashing, LSH）。通过构造一组哈希数，将相似的高维向量映射到同一哈希桶中，从而加速ANN搜索。
