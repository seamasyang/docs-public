
# 原子基本结构 学习笔记

## 一、原子的基本组成

**原子 = 原子核 + 核外电子**

**原子核 = 质子 + 中子**（氢-1 例外：原子核只有 1 个质子，无中子）

> 电子在核外并非经典“行星轨道”运动，而是以**量子概率分布**（电子云/原子轨道）存在。

---

## 二、三种亚原子粒子对比

| 粒子           | 符号 | 电荷                                             | 质量（约）                                                                       | 位置     | 作用                             |
| -------------- | ---- | ------------------------------------------------ | -------------------------------------------------------------------------------- | -------- | -------------------------------- |
| **质子** | p⁺  | \(+1e \approx +1.602\times10^{-19}\ \mathrm{C}\) | \(1.6726\times10^{-27}\ \mathrm{kg}\)（约 \(1.007276\ \mathrm{u}\)）             | 原子核内 | 决定元素种类（原子序数 \(Z\)）   |
| **中子** | n⁰  | \(0\)（电中性）                                  | \(1.6749\times10^{-27}\ \mathrm{kg}\)（约 \(1.008665\ \mathrm{u}\)，略大于质子） | 原子核内 | 决定同位素；参与核裂变/衰变      |
| **电子** | e⁻  | \(-1e \approx -1.602\times10^{-19}\ \mathrm{C}\) | 约 \(9.109\times10^{-31}\ \mathrm{kg}\)（约为质子质量的 \(1/1836\)）             | 核外空间 | 决定化学性质；参与成键、离子形成 |

> 质子与中子统称**核子**。原子质量几乎全部集中在原子核。

---

## 三、关键数量关系

**原子序数** **Z**=**质子数**

\**质量数** **A**=**质子数** **Z**+**中子数** **N**

\**中子数** **N**=**A**−**Z**

**中性原子：质子数**=**电子数**

**离子：**电荷数**=**质子数**−**电子数****

---

## 四、质量数、原子序数的符号表示

以 (^235_92U) 为例：

- **左上标 235** = 质量数 \(A\)（质子数 + 中子数），**不是精确原子质量**
- **左下标 92** = 原子序数 \(Z\)（质子数）
- **U** = 元素符号

> 质量数只是整数近似；真实原子质量会因结合能（质量亏损）略有偏离。例如 \(^{235}\mathrm{U}\) 原子质量约 \(235.0439\ \mathrm{u}\)，\(^{238}\mathrm{U}\) 约 \(238.0508\ \mathrm{u}\)。

---

## 五、同位素

**同一种元素**（质子数相同），**中子数不同**，互为同位素。

| 核素                 | 质子数 | 中子数 | 质量数 |
| -------------------- | ------ | ------ | ------ |
| \(^{235}\mathrm{U}\) | 92     | 143    | 235    |
| \(^{238}\mathrm{U}\) | 92     | 146    | 238    |

> 质子数决定**元素种类**；中子数决定**同位素种类**。同位素在周期表中占同一格。

---

## 六、离子：失去/得到电子

| 过程               | 结果                       | 原因                         | 示例             |
| ------------------ | -------------------------- | ---------------------------- | ---------------- |
| **失去电子** | **正离子（阳离子）** | 负电荷减少，正电荷“多出来” | Na → Na⁺ + e⁻ |
| **得到电子** | **负离子（阴离子）** | 多带负电荷                   | Cl + e⁻ → Cl⁻ |

- 失去 \(n\) 个电子 → 带 \(n+\) 电荷（如 Mg²⁺）
- 得到 \(n\) 个电子 → 带 \(n-\) 电荷（如 O²⁻）

> **不是“失去/得到都可正可负”**：失去电子必为正离子，得到电子必为负离子。

---

## 七、元素周期表的排列逻辑

- 周期表按**原子序数（质子数）递增**排列。
- 每一格代表**质子数相同的一类原子**（一个元素），不是某一个具体原子。
- **周期（行）** 和 **族（列）** 还反映**核外电子排布**，尤其最外层电子，体现化学性质规律。
- 历史注：门捷列夫早期按**原子量**排列，后来以**原子序数（质子数）**为本质依据。

---

## 八、更深层：夸克与强子

质子、中子不是最底层，它们由**夸克**组成。

### 夸克的六种“味”

| 夸克   | 符号 | 电荷     |
| ------ | ---- | -------- |
| 上夸克 | u    | \(+2/3\) |
| 下夸克 | d    | \(-1/3\) |
| 粲夸克 | c    | \(+2/3\) |
| 奇夸克 | s    | \(-1/3\) |
| 顶夸克 | t    | \(+2/3\) |
| 底夸克 | b    | \(-1/3\) |

每种夸克有对应的**反夸克**，电荷相反。

### 质子与中子的夸克组成

****质子** **p**=**uu**d +2/3 + 2/3 - 1/3 = +1**

**中子 n=udd: +2/3 - 1/3 - 1/3 = 0**

### 关键概念

- **夸克禁闭**：夸克不能单独自由存在，只能组成强子。
- **强子**：重子（3 个夸克，如 p、n）和介子（夸克 + 反夸克，如 \(\pi^+ = u\bar{d}\)）。
- **胶子**：传递强相互作用，带色荷，把夸克“粘”在一起。
- **质量来源**：质子/中子质量主要来自夸克动能和强相互作用场能，而非夸克裸质量。

## 九、易混淆点辨析

| 易混点                         | 正确理解                                                                  |
| ------------------------------ | ------------------------------------------------------------------------- |
| 质量数 = 精确原子质量？        | ❌ 质量数是整数近似，真实原子质量有微小偏离                               |
| 原子核一定含中子？             | ❌ 氢-1 原子核只有 1 个质子，无中子                                       |
| 电子像行星绕轨道转？           | ❌ 电子以量子概率分布（电子云）存在，无确定轨迹                           |
| 铀-238 裂变/衰变会变成铀-235？ | ❌ 二者是独立同位素；U-238 自发衰变最终到 Pb-206，吸收中子可转化为 Pu-239 |
| 失去/得到电子都可正可负？      | ❌ 失去电子→正离子；得到电子→负离子                                     |
| 元素周期表按原子量排？         | ❌ 本质按原子序数（质子数）排；原子量是早期历史依据                       |

## 十、一页速记

> **原子** = 原子核（质子 + 中子）+ 核外电子（概率云）
> **质子**带正电，决定元素种类（\(Z\)）
> **中子**不带电，决定同位素（\(N = A - Z\)）
> **电子**带负电，决定化学性质
> **中性原子**：质子数 = 电子数
> **离子**：失电子→正离子，得电子→负离子
> **周期表**：按质子数递增排列，每格代表一个元素（一类同位素原子）
> **质子/中子** = 夸克组成（p = uud，n = udd），由胶子通过强相互作用结合



# U的裂变和衰变

**U-238 + 慢中子** → 俘获 → U-239 → Np-239 → **Pu-239**
**U-238 + 快中子** → 可裂变 → 裂变碎片；也可俘获到 Pu-239
**U-238 自发衰变** → 铀系 → **Pb-206**
**U-235 + 慢中子** → 高效裂变 → 裂变碎片（质量数呈双峰分布的、包含数百种核素的庞杂碎片集合；代表性核素： **锶-90**，**铯-137，**碘-131****） + 中子 + 能量
**U-235 自发衰变** → 锕铀系 → **Pb-207**
