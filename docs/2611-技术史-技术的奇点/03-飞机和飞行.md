## 二、两条一直在拉的曲线

**涵道比（外涵流量 / 内涵流量）**——这条线几乎就是民航发动机进化史本身：

| 机型 / 发动机                 | 涵道比（约） |
| ----------------------------- | ------------ |
| 707（JT3D，涡喷改涡扇）       | ~1           |
| 747（JT9D）                   | ~4.3         |
| 737NG / A320ceo（CFM56）      | ~5–6        |
| C919（LEAP-1C）               | ~10 上下     |
| A220（PW1000G）/ 777X（GE9X） | ~10–12      |

代价随收益一起来：涵道比越大越省油越安静，但风扇直径越大、越重、**离地间隙越紧**。737 MAX 那个"底部被削平"的发动机短舱，就是被机身间隙逼出来的妥协化石。

**涡轮前温度**：Jumo 004 约 600 °C → 现代 1700 °C 以上，**已经超过镍基合金自身的熔点**，靠气膜冷却和热障涂层活着。省下来的油主要不是气动挣的，是材料挣的。

## 四、术语小卡

- **轴流式 / 离心式压气机**：空气平行于轴流动 vs 被甩到径向。轴流推力上限高。
- **自由涡轮**：不驱动压气机、只输出轴功率去转螺旋桨的那一段涡轮——涡桨的关键。
- **涵道比**：绕过燃烧室的那股空气 / 走核心机的空气。越大越省油越安静。
- **蠕变**：金属在高温 + 应力下缓慢塑性变形。这是卡住燃气轮机 130 年的那个东西。
- **功重比**：单位发动机重量输出的功率。活塞的天花板就死在这上面。



**活塞机**干的事是：燃气在气缸里爆炸膨胀，把活塞往下推，连杆把这个直线运动变成曲轴的旋转，四冲程走完进气—压缩—做功—排气。化学能 → 往复直线 → 旋转，中间必须经过"往复"这一步。
而这一步就是它的天花板。活塞每秒钟要上下几百次，质量来回加速、急停、反向——惯性力巨大，振动大，轴承和曲轴受罪，所以转速基本被锁死在两三千转（汽车能到六千转，航空发动机嫌太重）。功率再加，重量涨得比功率还快。这就是"功重比"这个词卡住活塞的地方。
涡轮干的事，是把"来回动"换成"一直转"：燃气连续不断地吹在叶片上，转子从头到尾只做一件事——转。没有往复件，没有爆炸冲击的顿挫，转速能上万。这是整段历史真正的分水岭，不是"烧油方式变了"，是运动形式变了。
然后涡桨和涡扇，是同一个核心机（压气机 + 燃烧室 + 涡轮）配了两种不同的"把功率传出去"的方式：
**涡桨**：涡轮螺旋桨发送机的简称。核心机后面再接一段"自由涡轮"——它不驱动压气机，专门输出轴功率，通过减速器去转外面那副大螺旋桨。推力的九成以上来自螺旋桨，喷出去的那股气基本是零头。所以你可以把它理解成"拿燃气轮机当发动机的螺旋桨飞机"。桨必须做得很大才能抓住空气，但大桨叶尖一接近音速阻力就炸，于是被锁在五六百公里每小时。
**涡扇**：把螺旋桨做小、加多叶片、塞进整流罩里，直接用涡轮驱动，不再要减速器。风扇吹出去的那股空气走外涵道——绕开燃烧室，根本没烧过，只是被加速往后推。现代客机涵道比十左右，意思是每十份推力里大概九份来自这股"冷"空气。
所以有意思的结论是：涡扇其实是涡桨的封闭版，两者都不是"靠喷气推进"。真正靠喷气的涡喷只剩军机加力——因为超音速时外面那圈风扇反而添阻力。
一个直觉检验：涡扇飞机看起来是"喷气式"，但它的本质更像一台藏在管子里、转速上万的大风扇。你觉得这个说法别扭吗？我第一次读到涵道比的时候，卡的就是这儿——"喷气客机"这个名字其实一直在误导人。
