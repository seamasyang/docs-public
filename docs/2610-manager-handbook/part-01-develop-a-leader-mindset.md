## 01 trasition to leadership

### 理解管理者的角色

管理者最基础的工作：为团队设定方向并协调资源以实现组织目标。

上级关注你：战略规划执行和资源配置效率、公司目标完成、风险控制，以及组织绩效。

下级关注你：指明战略目标、支持团队完成任务，解决问题，果断回答问题，并促进团队成长。

| 角色   | 任务                     |
| ------ | ------------------------ |
| 个人   | 完成特定的任务           |
| 管理者 | 帮助下属独立完成特定任务 |

职位的权威性意味着管理者必须更加积极地响应下属和组织的需求。不能简单的公布一个新的计划，还需要说服团队倾尽全力

### 管理和领导的区别

约翰·科特（John Kotter）经典框架 - 关于管理与领导的核心框架： （1）管理与领导的本质区分；（2）八步变革模型（略）

> **管理是为了让系统在复杂环境中稳定运转（让事情做对）；领导是为了让系统在变化环境中找到新方向（做对的事）。**

| 维度         | 管理                   | 领导                       |
| ------------ | ---------------------- | -------------------------- |
| 核心问题     | 如何在复杂中保持秩序？ | 如何在变化中找准方向？     |
| 时间视角     | 短期到中期，计划与预算 | 长期，方向与愿景           |
| 对待不确定性 | 降低不确定性，控制风险 | 拥抱不确定性，从中发现机会 |
| 权力来源     | 职位权威、制度流程     | 个人影响力、信任与感召     |
| 成功标准     | 稳定、高效、可预测     | 变革、适应、成长           |

 **管理强调管控和预见性** ：

* 管控：通过制度、流程、KPI、预算、审计等手段，确保行为不偏离计划。
* 预见性：通过规划、预测、风险评估，尽量把未来变成可控的。
* 例子：年度预算、人员编制、绩效考核、流程标准化。

 **领导强调愿景和机会** ：

* 愿景：描绘一个值得追求的 future state，让人们知道“我们要去哪里”。
* 机会：在不确定中看到别人没看到的方向，敢于下注。
* 例子：设定战略方向、调整组织架构、激发团队动力、塑造文化。

| 管理行为                       | 领导行为                           |
| ------------------------------ | ---------------------------------- |
| 规划：制定详细步骤和时间表     | 设定方向：提出愿景和战略           |
| 预算：分配资源、控制成本       | 调整人员：把对的人放到对的位置     |
| 人员配置：按岗位需求招人、排班 | 激发动力：让员工认同目标、主动投入 |
| 控制：监督执行、纠正偏差       | 激励：满足深层需求、鼓舞士气       |

### 揭秘领导

领导特质：智慧、自信、远见、口才、勇气、魅力和果断常见领导特质

> 1. 智力
>    * 了解情况：对自己的行业、业务和优先事项是否了解和熟悉
>    * 关注未来：是否根据长期优先事项安排短期任务
>    * 果断：在无法获得所有事实的情况下做出决定吗？能否做艰难的选择？
>    * 适应模糊性：在不确定的环境中，在几乎没有可靠路标的情况下工作吗？能很好地适应变化吗？
> 2. 社会情感
>    * 自我意识：会注意自己的行为如何影响他们吗？
>    * 认同：对别人的需求、顾虑和目标有同理心吗？
>    * 稳定：是否保持积极、专注的观点，并在动荡和混乱中继续发挥领导作用？
>    * 值得信赖：行为是否符合价值观？是否信守承诺？
> 3. 组织
>    * 协作：是否经常与上级、同事和团队一起工作，交付出色的团队成果
>    * 影响力：是否认真倾听，找到共同点，并清楚地表达自己的观点，以说服和推动组织取得积极成果
>    * 政治敏锐：你了解公司的权力结构吗？你了解关键人物的想法吗？你知道从哪里寻求支持和支援吗？
>    * 刺激性：你会挑战现状吗？你会说服别人设定高标准和高目标吗？

* **同理心** ：设身处地理解对方，并让对方感到被看见。= 理解+关怀+尊总
* **同情心** ：为对方难过，想关心对方，但不一定懂对方。=关怀为主
* **共情** ：感受对方的情绪，和对方的情绪共振，偏心理学表达。=理解为主

<span style="color: red;">同理心最强调平等和尊重；同情容易俯视；共情容易卷入</span>

## 02 building trust and credibility

> 如何管理前同事
>
> - 让人们意识到这种转变：理想情况下，团队会从其他人——即将离任的上级或其他主管——那里得知你升职的消息。确保有一个发布消息的计划。
> - 不要马上实施重大变化：激进的改变看起来像是否定你的前任，但你不知道他们的支持者会怎么想。
> - 与团队成员一对一沟通：花时间和每个人分享你的远景并寻求反馈。“我能做些什么帮助你成功？”
> - 保持距离：继续以过去的方式与人交往，你就会模糊界定自己新角色的界限，让人指责你在偏袒别人。
> - 与竞争对手和平共处：如果和同事竞争这份工作，就要坦诚面对他们的沮丧。不要过于奉承他们的贡献，否则会让人感觉你在幸灾乐祸。如果希望获得支持，则采取一定的行动，如给他们分配一项重要任务。

### 塑造品格

通过以下方式展示对团队的关注

- 争取一致性：言行一致。如果团队强调严谨性和准确性，那么以身作则，并请团队来进行评价。
- 调节情绪：当面临巨大压力时，你不会奔溃或大发雷霆。避免出现绝望和沮丧等极端情绪，而且在遇到困难时不要迁怒他们。
- 注意举止：尊重每个人。要有礼貌、及时回复邮件，准时开始和结束会议。走廊上和人打招呼，倾听时要有眼神交流，开会时不要同时处理多项任务。
- 学会提问：提问不仅能手机信息，还能传递信息——你是谁，你关心什么，以及你如何看待对方。
- 征求反馈：向他人征求反馈意见并采取行动，表明你关心自己对他们的影响。
- 给他们展示自己的机会：积极利用员工的知识，向员工证明你真心欢迎他们的意见。认可个人的贡献。

### 展示能力

- 争取速赢
- 直面棘手问题，推到拦路虎
- 研究想法
- 解释决定和行动
- 坦诚无知
- 准备好后备力量
- 请其它人测试你的想法的价值

### 培养真诚领导力

- 从自己的人生故事中学起
- 理解外在动机和内在动机
- 培养自我认知

### 道德和诚信

- 首先、树立道德和行为准则的榜样
  - 对于艰难的决策，要勇于承担责任
  - 公开审视自己的决策是否存在偏差
  - 对所有公司利益相关方都表现出真诚的关心
- 其次、必须确保团队成员的道德行为

> 行动清单
>
> - 下次团队会议，准备一些针对特定人员提出的问题。项目中的学到了哪些东西？
> - 当做出重大决定时，清楚地阐述如何得出结论，包括进行了什么样的研究，有哪些因素支撑你的选择
> - 使用“培养自己成为真诚的领导者”中的内容，反思自己的北京和经历
> - 在自己和团队的决策过程中，将道德问题作为一个常规性因素考虑进去
> - 公开承认自己的偏见，并要求团队其他成员也这样做。

## 03 emotional intelligence

情商：准确感知自己和他人情绪的能力，理解情绪对人机关机传递信号的能力，以及管理自己和他人情绪的能力。


### 什么是情商

情商的五个核心

| 成分               | 含义                                                                       | 特质                                                     |
| ------------------ | -------------------------------------------------------------------------- | -------------------------------------------------------- |
| **自我观察** | 识别和理解自己的心情、情绪和驱动力，<br />以及它们对他人的影响的能力       | 自信<br />如实评测<br />自嘲式幽默                       |
| **自我调节** | 控制或改变破坏性重新和心情的能力<br />暂停判断的倾向，行动前三思           | 诚实正直<br />适应性模糊<br />接受改变                   |
| **动机**     | 出于金钱或地位之外的原因，对工作充满热情<br />精力充沛、坚持不懈地追求目标 | 实现目标的强烈动力<br />乐观、即使面对失败<br />组织承诺 |
| **同理心**   | 理解他人情绪构成的能力。<br />根据他人的情绪反应来应对他人的能力           | 善于培养和留住人才<br />跨文化的敏感性<br />为客户服务   |
| **社交技能** | 熟练管理关系和建立网络<br />找到共同点并建立融洽关系的能力                 | 领导变革的有效性<br />说服力<br />有组建和领导团队的经验 |




### 自我觉察的力量

不适应行为包括：拖延、否认、焦虑、嫉妒、自虐、攻击性、防御性、被动攻击性

### 情绪稳定和自控

- 首先、团队会对你的情绪做出反应
- 其次，稳定的情绪能避免冲动决策
- 最后，自我控制体现了诚信

### 管理员工的情绪

1. 察觉情绪
2. 练习积极倾听
3. 重塑员工的情绪
4. 温和地捍卫团队准则。指出不可接受行为，尤其是涉及其他人时。
5. 适时道歉或表示同情

### 培养团队的社会意识

1. 制定并坚持遵守行为准则
2. 在任务中抽出时间
   * 定期组织团队外出活动，让大家有机会更好地了解彼此
   * 在定期会议开始时，安排轻松开场，询问每个人的近况
   * 关注并讨论团队整体的情绪状态
   * 表达对团队各种情绪的接纳
   * 以灵活的方式提供支持
3. 当遇到难事时
   * 坚信团队可以应对挑战
   * 用有趣的方式来识别并缓解压力和紧张情绪
   * 提醒大家团队的使命和远大目标
   * 回顾团队之前是如何解决类似问题的
   * 关注可控因素，集中精力解决问题，而不是归咎责备
4. 在做决策时
   * 询问所有人是否都赞同这个决定
   * 询问沉默的成员们的想法
   * 尊重个人的独特性和不同观点
   * 认可成员受到攻击，切勿贬低或侮辱

## 04 prositioning yourself for success

### 重新定义成功

- 明确团队成员的期待
- 实现团队的目标和任务
- 通过团队的成就进一步实现公司的目标
- 提高员工技能并高校管理他们的工作

### 了解组织战略

1. 收集战略目标的信息 (组织、团队、自己)
2. 分析战略风险
   * 未来发展中，主要的不确定性来源
   * 识别出哪些可能威胁到你成功的因素？ 职业目标、培训、资格认证、社交网络，工作环境
   * 识别哪些可能威胁到你成功的跟人风险？ 健康状况、家庭财务、个性

### 做好规划，实现战略一致
