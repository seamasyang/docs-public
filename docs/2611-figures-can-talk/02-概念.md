
# 什么是审计 · 概念速览（7 页）

> 全书主线：**审计是什么 → 谁在做 → 收多少钱 → 怎么走流程 → 一纸合同 → 一份声明 → 一份建议书**

---

## 第 1 页｜什么是审计？

*一句话定义 · 三条支撑 · 三种审计的分界（从业者速览）*

> **结论｜** 审计是独立第三方对管理层编报的财务报表出具的鉴证意见：它在所有重大方面真实公允，而且这句话是可被追责的。

### ① 概念 · 审计是什么

- 谁做：独立的、公正的、有能力的第三方
- 查什么：管理层编报的财务报表（报表是企业的作品）
- 交付：一两页审计意见，只说一句——真实公允

### ② 判断 · 结论的边界与硬度

- 四种意见：无保留 / 保留 / 否定 / 无法表示
- 三个限定：所有重大方面 · 合理保证 · 按准则公允反映
- 四不是：查问题 · 经济警察 · 舞弊调查 · 内控审计

### ③ 论证 · 它为什么必须存在

- 两权分离 ＋ 道德不健全 → 所有者不信管理者
- 自己查不专业、不中立、管理者不服 → 请独立第三方
- 故：工作量由风险（被起诉）决定，不由收费决定

### 表：三种审计——手段相通，目的不同

| 维度   | 政府审计                                       | 企业内部审计                                   | 独立审计（注册会计师）                                                   |
| ------ | ---------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------ |
| 谁做   | 国家审计署                                     | 企业内设检查职能；小企业常由总经理或总经办代行 | 会计师事务所                                                             |
| 目的   | 查规章制度执行，护国有资产安全有效             | 因项目而异：有时查问题，有时做证明题           | 对财务报表发表意见，提供合理保证                                         |
| 手段   | 翻查大量原始单据查合规，深度广度远高于外部审计 | 视项目而定                                     | 先测内控（内控，就像一台摄像机，有助于看清业务怎么运转），再做实质性测试 |
| 一句话 | 查合规                                         | 看目的                                         | 出意见                                                                   |

> **书中原话逻辑 · 2.2.2 审计与人性恶**
> “审计竟建立在彼此不信任之上——但正因如此，所有权与经营权得以进一步分离，企业才可能越做越大。”

> **别误读：** 审计 ≠ 查问题 ≠ 经济警察 ≠ 舞弊调查 ≠ 绝对保证；成果只有那一两页意见，一字千金。

## 第 2 页｜会计师事务所与注册会计师

*两个人称 · 三种组织形式 · 一套责任安排（从业者速览）*

> **结论｜** 注册会计师是执业主体，会计师事务所是执业外壳：个人不能单独执业，签字的只是按质控规矩办事的人，真正对质量负责的是合伙人整体。

### ① 概念 · 一个主体，一个外壳

- 注册会计师（俗称审计师）：独立审计的执业人士
- 会计师事务所：审计师组合、对外承揽业务的机构；个人须入所才能执业
- 易混：名字像会计，被当成“做账的”；审计署就不会搞错

### ② 判断 · 组织形式＝责任安排

- 合伙制＝无限责任：一人出错，全体合伙人以全部身家赔
- → 所以只与充分信任的人合伙，这就是“人合”
- 有限责任公司：只赔注册资本，更易为利益牺牲独立性
- 特殊普通合伙（LLP）：责任适度分离，无过错者不买单

### ③ 论证 · 为什么必须“人合”而非“资合”

- 卖的是专业判断与职业操守，不是资本（卖油翁：唯手熟尔）
- 审计“人多好打狼”：至少四人，常十人百人 → 靠整体质控
- 故：合伙人审阅底稿、制定质控、签发报告，是真正的责任人

### 表：三种组织形式——责任怎么分，质量才有保证

| 维度     | 有限责任公司                             | 普通合伙                                     | 特殊普通合伙（LLP）                        |
| -------- | ---------------------------------------- | -------------------------------------------- | ------------------------------------------ |
| 责任范围 | 以注册资本为限，伤不到合伙人个人财富     | 无限责任；任一合伙人出错，全体以全部身家赔偿 | 责任适度分离；无过错者不为他人重大过失买单 |
| 风险意识 | 失手只“牺牲我一个”，易为利益牺牲独立性 | 出事倾家荡产，风险意识最强                   | 保留约束又不株连，重质量管控与责任约束     |
| 适合规模 | 历史主流（法律规定所致）                 | 小型事务所                                   | 大中型事务所                               |
| 现状趋势 | 2010 年至今占比逐年下降                  | 占比明显上升                                 | 2010 年财政部推动，占比明显上升            |

> **书中原话 · 2.4.1 会计师事务所与注册会计师个人的关系**
> “很多所里大家都不愿意签字，以至于还要给肯签字的注册会计师一笔签字费。”签字只代表你在按所里的质控规矩做事。

> **法规坐标：** 《注册会计师法》是根本；24 号令《会计师事务所审批和监督暂行办法》效力仅次于它。

## 第 3 页｜审计费是怎么定的

*费率 × 工时 → 全额 → 谈判折扣 → 事中调整（从业者速览）*

> **结论｜** 审计费用“费率表 × 人员时间预算”算出的全额，再经谈判打折；它既是商业价格，也是审计师自己预估工时和风险的结果。

### ① 概念 · 这笔钱是怎么算出来的

- 费率表：按员工级别与经验定价，可对外公布，与工资有比例关系
- 时间预算：估计需要什么级别的人、各干多长时间
- 两者相乘＝全额（打折前）；愿按全额付的客户被叫作“羊牯”

### ② 判断 · 报价会怎么变

- 折扣：谈判后给出，可能是 10%、30%，甚至 50%
- 看的是双方谈判地位、策略与技巧
- 调价：遇特殊情况事前提议，需客户同意
- 但只见过往上调，没见过因变简单往下调

### ③ 论证 · 为什么按费率而非按规模

- 卖的是人的时间与判断，成本＝人 × 小时，费率制才配得上成本
- 国外事务所、律师事务所、咨询公司普遍如此
- 按资产／收入规模收费“很不科学”：档案是否整齐、业务复杂度、组织架构，都影响工作量

### 表：一笔审计费的四个环节

| 环节     | 怎么做                             | 书上点破的细节                                       |
| -------- | ---------------------------------- | ---------------------------------------------------- |
| 计价基础 | 级别费率表 × 人员时间预算         | 得全额＝打折前的报价；愿按全额付的客户被叫作“羊牯” |
| 谈判折扣 | 在全额基础上给出折扣               | 10%、30%、50% 都可能，看双方谈判地位、策略与技巧     |
| 事中调整 | 遇特殊情况，事先取得客户同意后调价 | 只见过因麻烦往上调，没见过因变简单往下调             |
| 替代定价 | 按客户资产规模与收入规模收费       | 书评“很不科学”：工作量是多因素结果，不止看规模     |

> **书中原话 · 2.4.4 审计费是怎么定的**
> “赚了归自己，亏了大家摊”：调价只朝上走。而客户对自己业务有多复杂门儿清，审计师进场前并不知道——低估才是常态。

> **生态平衡：** 审计师提管理建议书 → 客户改内控 → 次年审计更省力；改不动，就只剩加审计费（2.7）。

## 第 4 页｜注册会计师审计的流程

*接活 → 定范围 → 签约定书 → 测内控 → 做实质 → 出意见（从业者速览）*

> **结论｜** 流程是「先定范围、再判风险、后定程序」的链条：范围写进业务约定书，内控质量决定实质性测试做多少，终点只是一两页的审计意见。

### ① 概念 · 六个环节

- 接触与初判：索要初步资料，判断难度、风险、工作量
- 定范围：工作范围＝客户购买“产品”的产品描述
- 项目建议书 → 业务约定书：正式确定买卖关系（客户或先要保密协议）
- 测内控 → 做实质 → 签发审计报告

### ② 判断 · 关键判断点

- 内控先“有罪推定”：测得越多、证据越多，才敢少做实质
- 内控只看签字、不看控制实质，是最常见的错误
- 实质测试查出严重错误 → 推翻内控结论、扩大样本
- 不论内控好坏，每个科目都仍要做实质性测试

### ③ 论证 · 为什么是这个顺序

- 受托审计：范围没谈清，后面全是扯皮
- 风险决定工作量：十天有十天的做法，一天有一天的做法
- 先画轮廓再补细节：先攻风险最大的领域
- 终点只有一两页：流程交的是“意见”，不是“账”

### 表：流程六步——每步交什么、容易错在哪

| 环节          | 做什么                                                   | 关键点 / 易错处                          |
| ------------- | -------------------------------------------------------- | ---------------------------------------- |
| ① 接触与初判 | 索要初步资料，判断难度、风险、工作量                     | 报价与时间预算的起点                     |
| ② 谈工作范围 | 范围＝客户购买的“产品描述”                             | 受托审计：先讲清受的是何种托付           |
| ③ 项目建议书 | 按工作范围提交，客户认可后再走下一步                     | 范围不清，后面就容易扯皮                 |
| ④ 业务约定书 | 正式签约，确定双方的买卖关系                             | 先签后干活；日期不得晚于审计报告日       |
| ⑤ 内控测试   | 自上而下：企业层面＋流程层面；询问、观察、检查、重新执行 | 只追求形式完美（只看签字），不看控制实质 |
| ⑥ 实质性测试 | 分析性复核＋详细测试；不论内控好坏，每个科目都要做       | 内控好＝可以少做，不是不做               |

> **书中原话 · 2.4.5 流程 / 3.1.7 内控与实质的关系**
> 内控测试与实质性测试：先对内控做“有罪推定”，测得多、证据多，才敢把实质性测试做少；一旦实质测试查出严重错误，就要回来推翻结论。

> **铁律：** 先签业务约定书、后干活。约定书日期最迟要早于审计工作的最后一天——因为审计报告日就是审计工作结束那天（2.5.1）。

## 第 5 页｜业务约定书

*一份标准合同：写清干什么活、拿多少钱，且先签后干（从业者速览）*

> **结论｜** 业务约定书把「工作范围＋收费＋双方责任」写成合同：先签后干活，日期不得晚于审计报告日；它的前身是项目建议书，但法律效力天差地别。

### ① 概念 · 必备与可选条款

- 必备：目标与范围；注册会计师的责任；管理层的责任
- 必备：适用的财务报告编制基础
- 必备：拟出具审计报告的预期形式与内容
- 可选：利用专家与内审、与前任注册会计师沟通、底稿提供义务

### ② 判断 · 建议书 ≠ 约定书

- 英语里求婚＝proposal，订婚＝engagement
- 建议书＝谈恋爱时说的话；约定书＝结婚后打算做的事
- 建议书无严格法律约束力：说成牡丹花都行
- 约定书有法律约束力：说自己是一朵花就是欺诈

### ③ 论证 · 为什么必须“先签后干”

- 合同须先于劳动，否则责任与收费都没落地
- 否则就是“只管低头拉车，不管抬头看路”
- 活干完还没签回＝“现上轿现扎耳朵眼”
- 底线：日期最迟早于审计工作最后一天（报告日＝结束日）

### 表：项目建议书 vs 业务约定书

| 维度     | 项目建议书（proposal）                 | 业务约定书（engagement letter）     |
| -------- | -------------------------------------- | ----------------------------------- |
| 比喻     | 谈恋爱时说的话（求婚 proposal）        | 结婚后打算做的事（订婚 engagement） |
| 性质     | 宣传性材料，无严格法律约束力           | 标准合同形式的法律文件              |
| 能说什么 | 经验、特长随便夸，“说成牡丹花都行”   | 必须老实：说自己是一朵花就是欺诈    |
| 核心内容 | 方案、范围、报价                       | 双方责任与义务：干什么活、拿多少钱  |
| 风险     | 说了可以不算数（“那时说的不算数啦”） | 没签就干活：现上轿现扎耳朵眼        |

> **书中原话 · 2.5.3 业务约定书和项目建议书的区别**
> “哎呀，那时候我不是想讨你欢喜嘛，那时候说的不算数啦。”——项目建议书可以不算数；真实年龄要到现场工作才露出来。

> **所内纪律：** 现场工作开始前问一句“约定书签回来了吗”。标准模板就是自家的地盘——狗打架都在自己地盘上打（2.5.2）。

## 第 6 页｜声明书

*管理层写给审计师的一封“宣誓信”：既非无用，也非万能（从业者速览）*

> **结论｜** 声明书是审计师拟稿、以管理层口吻签回的确认信，用来兜住“证据拿不彻底”的科目与事项：它是有用的终极武器，但绝不能替代审计证据。

### ① 概念 · 它是什么

- 审计师拟好内容、以客户管理层口气写给审计师的信
- 相当于法庭宣誓：讲出事实，完整的事实，绝不说假话
- 典型条款：已履行约定书责任、资料与交易已全部提供入账
- 还确认：估计假设合理、无舞弊违规、或有与关联方未隐瞒

### ② 判准 · 两种错误倾向都不行

- 无用论：反正是张纸，签了照样造假
- 万能论：写进声明书就算工作做到家了
- 反例：存货跌价准备 320 万写进声明书就收工
- 真上法庭，控方只问一句：你对它做了什么工作？

### ③ 论证 · 为什么它真有用

- 实战：把不放心的事项全写进去，管理层会逐字研究
- 结果：死活不签、要求改词，反而吐出隐情
- 战术：对不熟外部审计的客户，先把声明书讲清楚
- 定位：只兜证据拿不彻底的部分，主体工作仍靠程序

### 表：声明书兜住的五类“审计难点”

| 声明什么                                   | 对应哪类难点                   | 审计师怎么用               |
| ------------------------------------------ | ------------------------------ | -------------------------- |
| 完整性声明：资料与交易已全部提供、全部入账 | 漏了什么看不见，完整性最难证明 | 声明兜底，再配专门程序     |
| 估计与假设：会计估计的重大假设是合理的     | 假设是管理层的判断，不是事实   | 复核假设依据，声明锁定口径 |
| 舞弊与违规：不存在也没有隐瞒               | 舞弊本就难被发现               | 声明＋舞弊后挂程序         |
| 或有、期后、关联方：没有隐瞒               | 存在性靠管理层主动说           | 声明＋函证与检查           |
| 计划与意图：已如实说明                     | 意图看不见、摸不着             | 访谈＋声明固定说法         |

> **书中原话 · 2.6.2 驳“声明书无用论”**
> 管理层一改敷衍态度，把声明书的措词研究了半天，然后死活不签，一定要求改掉某些说法——追问之下，我们才开始知道一些新的事情。

> **别过头：** 若“财务报表真实公允”也能由客户写进声明书，我们就能收队回家了。声明书每一句后面，都得有程序撑着（2.6.3）。

## 第 7 页｜管理建议书

*审计的“买一送一”：不是准则要求，却决定客户觉得值不值（从业者速览）*

> **结论｜** 管理建议书是审计过程的副产品：不是准则要求的活，却承担三个目的：让下次审计更省力、让客户觉得审计费花得值、给自己留一块挡箭牌；而“出彩又不惹事”靠的是换角度和收措辞。

### ① 概念 · 它是什么、给谁看

- 审计过程的副产品：不在准则要求内，属“买一送一”送的那个“一”
- 内容：与财务报告有关的内控制度缺陷 ＋ 改进建议
- 首先出给管理层，好让他们照着整改
- 同时抄给股东与董事会：防“老鼠看仓，看个精光”

### ② 判断 · 三个目的，一个推论

- 为下次铺路：内控改好 → 更多依赖 → 工作量下降
- 让客户觉得值：这审计费花得不冤（增值服务）
- 挡箭牌：已书面提醒过，真出事时有话可说
- 推论：客户未必买账；风险不大也照写不误

### ③ 论证 · 怎么写才出彩又不惹事

- 换角度：别写“审计难做”，写管理风险与客户满意度
- 收措辞：知之为知之，不把想象和道听途说当事实
- 不夸大：只有一两个事例，就如实写一两个事例
- 每句话都要经得起任何人的“辩解”（忠言逆耳）

### 表：一份管理建议书里的四种立场

| 角色         | 想要什么                  | 于是现实是这样                     |
| ------------ | ------------------------- | ---------------------------------- |
| 管理层       | 整改省事、别被挑刺        | 敷衍了事：甚至故意留着漏洞浑水摸鱼 |
| 股东与董事会 | 想知道底下到底发生了什么  | 建议书要抄给他们，防“老鼠看仓”   |
| 审计师       | 下次省力 ＋ 将来免责      | 风险不大的事也愿意写进去           |
| 客户高层     | 真能落地的增值建议        | 多数被评为“找事的／没营养”       |
| 资深审计师   | 写出让 CFO 眼前一亮的条目 | 感叹这是“用绳命在创作”           |

> **书中原话 · 2.7.1 什么是“管理建议书”**
> 写管理建议书不是审计准则要求审计师的工作，因此这项工作属于“买一送一”里送的那个“一”。——超市里买袋大米，还经常送瓶油呢。

> **措辞铁律：** 只看到一两个事例，就只写一两个事例；别夸大成整年没人做对过事。你写的每句话，都得经得起任何人的“辩解”（2.7.1）。

### 全书纵向看：七页连成一条执业链

1. **第 1 页**给出目的与边界：审计卖的是“意见”，不是“查问题”；
2. **第 2 页**给出主体：意见必须挂在某个负无限／连带责任的合伙人身上；
3. **第 3 页**给出价格：费率 × 工时，风险决定工作量而非收费；
4. **第 4 页**给出过程：范围 → 风险 → 程序 → 意见；
5. **第 5 页**把范围与收费固定成合同（先签后干）；
6. **第 6 页**把证据拿不彻底的部分转成管理层的书面承诺；
7. **第 7 页**把审计的副产品变成客户眼里的“价值”，也顺手给自己留了退路。
