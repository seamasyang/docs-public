## 定义

特定环境中，具备感知、理解、推理、决策等能力，并采取行动以实现既定目标的智能系统

## 核心特征

自主性、感知能力、推理和决策能力、行动能力、持续学习与自我优化

## 核心组件和架构

1. 感知与输入处理
2. 上下文与记忆管理
3. 推理与决策引擎
4. 工具与API集成
5. 输出生成与响应
6. 监控与反馈

## 技术本质与能力边界

### 本质： 自治 + 任务导向

### 能力边界：系统性智能行为

1. 自主目标设定
2. 多agent协作与分工
3. 反思与自我修正
4. 跨模态与跨系统能力

## 技术框架

### langchain:  chains, tools, agents

### langgraph:  DAG、 ReAct （= reasoning + acting + observing + reflecting）

## 应用场景

1. 对话助手与办公协同
2. 企业知识库管理与检索增强
3. 学术研究与智能信息检索
4. 智能数据分析与自动化决策
5. 多模态感知与情感交互体验
6. 自动软件开发与系统运维
7. 复杂决策支持与多agent协作
