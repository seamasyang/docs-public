### 天文灾害

***超新星*爆发**是宇宙中某些恒星在演化末期经历的 **剧烈爆炸** ，它并非新星的诞生，而是一颗恒星走向毁灭的“死亡绝唱”。在短短数周至数月内，它释放的能量可与太阳一生辐射的总和相当，光芒足以照亮其所在的整个星系。

超新星爆发的核心机制只有两种，但它们对应着完全不同的恒星演化路径。

1. **核心坍缩**：大质量恒星的引力终结
   这是大质量恒星（通常质量超过8倍太阳质量）的宿命。当这类恒星核心的核聚变进行到铁元素时，聚变不再释放能量，反而会消耗能量。失去了能量支撑的核心在自身巨大引力下于不到一秒内急剧坍缩，形成中子星或黑洞，并释放出惊人的引力势能，将恒星外层物质以极高速度抛射出去。
2. **热核爆炸**：白矮星的失控燃烧
   这类爆发发生在双星系统中。一颗致密的碳氧白矮星从它的伴星吸积物质，当质量逼近一个临界值——钱德拉塞卡极限（约1.4倍太阳质量）时，其内部的温度和压力会触发碳氧核聚变的失控式爆发，将整个白矮星炸得粉碎，不留任何致密残骸

**核聚变** ，一句话说，就是**两个较轻的原子核在极端条件下结合成一个较重的原子核，并在这个过程中释放出巨大能量**

> **氘（²H）+ 氚（³H）→ 氦-4（⁴He）+ 中子 + 约17.6 MeV能量**

氘和氚都是氢的同位素。它们结合后生成氦-4和一个中子，同时释放出高能中子携带的能量。

太阳内部则主要是 **质子-质子链反应** ：4个氢原子核经过一系列步骤最终聚变成1个氦-4核，释放能量

### 为什么能释放能量？

关键在于 **质量亏损** 。聚变后的原子核更稳定，总质量比反应前略小。损失的质量并没有真正“消失”，而是转化为能量释放出来。因为光速 c 非常大，E=mc² 意味着极小的质量亏损也能对应巨大的能量。

### 一个重要边界：铁

恒星内部通过核聚变逐步把氢变成氦、碳、氧……一直到铁。 **比铁轻的元素聚变一般释放能量，比铁重的元素聚变则要吸收能量** 。所以大质量恒星核心变成铁后，聚变无法继续产能，核心失去支撑而坍缩，这正是超新星爆发的重要前提之一

| **核聚变** | **核裂变**         |
| ---------------- | ------------------------ |
| 过程             | 轻核合成重核             |
| 典型燃料         | 氢的同位素（氘、氚）     |
| 能量释放         | 单位质量燃料释放能量更大 |
| 太阳             | 靠核聚变发光             |
| 难点             | 需要极高温高压约束       |

**裂变产物的总质量比原来的铀-235加中子略小** 。这部分“亏损的质量”按 E=mc² 转化为能量，主要表现为裂变碎片的动能、中子动能和γ射线等

**伽马射线暴**是一种短暂且剧烈高频率电磁辐射爆发现象

> 长伽马射线暴通常由大质量恒星的坍缩引发，这一过程同时也产生了一次特殊的超新星爆炸，因此二者在宇宙同一地点“成协”出现。而短伽马射线暴则源于致密星并合，与超新星爆发是完全不同的物理过程。

**电磁辐射** ，简单说就是： **能量以电磁波的形式在空间中传播** 。它由相互垂直、交替变化的**电场**和**磁场**组成，在真空中以光速 **c** 传播，不需要介质

**电荷周围有电场；电荷运动产生磁场；电荷加速时，电场和磁场交替变化并向外传播，形成电磁辐射。**

**电场**是电荷周围空间中存在的一种物理场。它的核心作用是： **对放入其中的其他电荷施加电力** 。

**磁场**是运动电荷、磁体或变化电场周围存在的一种物理场。它的核心作用是： **对运动电荷、电流和磁体施加磁力** 。

电场和磁场不是完全独立的两件事，而是 **电磁场的两个侧面** ：

* **静止电荷** ：周围主要是电场。
* **匀速运动的电荷** ：周围同时有电场和磁场。
* **加速运动的电荷** ：电场和磁场发生变化，并向外传播，形成**电磁波**

所以：

> **电场 + 磁场 + 相互作用 = 电磁场。电磁波就是电磁场的波动传播。**

光、无线电波、微波、红外线、可见光、紫外线、X射线、γ射线，本质上都是电磁波。

**辐射**这个词要单独理解：它说的不是“场本身”，而是 **能量从某个源向外传播的过程** 。两类：电磁辐射、粒子辐射

### 和“核辐射”的区别

“核辐射”通常指放射性核素发出的粒子或射线，包括 α粒子、β粒子、中子、γ射线等。其中  **γ射线是电磁辐射** ，但 α、β、中子不是电磁辐射。所以：

> **电磁辐射 ≠ 核辐射的全部；γ射线只是电磁辐射中的高能频段。**

### 小行星和彗星撞击

**小行星**是太阳系内主要由**岩石、金属**构成的小天体，通常没有明显的挥发性物质活动。

* **成分** ：岩石、金属（铁镍等），含少量水冰或有机物，但整体以难挥发物质为主。
* **外观** ：形状多不规则，表面有撞击坑。
* **轨道** ：大多集中在 **火星和木星之间的小行星带** ；也有近地小行星、木星特洛伊小行星、柯伊伯带天体等。
* **活动** ：一般没有彗发和彗尾。少数“活跃小行星”会因碰撞、自转过快或含冰而短暂喷出尘埃。
* **来源** ：主要是太阳系内侧形成时未能聚合成行星的残余物质。

一句话：**小行星更像“岩石块”，主要来自太阳系较内侧，通常不冒气、不拖尾。**

**彗星**是主要由**冰、尘埃、岩石**组成的小天体，来自太阳系外围寒冷区域。

* **成分** ：水冰、二氧化碳冰、一氧化碳冰、氨、甲烷等挥发物，混合尘埃和岩石，常被形容为“脏雪球”。
* **来源** ：主要来自**柯伊伯带**和更远的 **奥尔特云** 。
* **轨道** ：很多彗星轨道偏心率大、倾角大，有的周期很短，有的要上万年才回归一次。
* **活动** ：靠近太阳时，冰升华成气体，形成 **彗发** （围绕彗核的朦胧气体尘埃云）和 **彗尾** （离子尾、尘埃尾）。
* **外观** ：远离太阳时可能只是一个暗淡的冰质小天体；靠近太阳时才变得明亮并拖尾。

一句话：**彗星更像“冰质天体”，来自太阳系外围，靠近太阳时会挥发形成彗发和彗尾。**

### 气候变化

《巴黎约定》全球气温上升幅度控制在1.5摄氏度以下。减少温室气体排放，增加可再生资源，提高能源效率。


### 定义

天气：通过温度，压力，湿度，降水量，日照，云量和风向测量的大气的当前状态。

气候：地球上某个特定区域一年内的地表和空气温度，气压，温度，降水量，日照，云量和风等历经几十年的平均值

气候变化：几十年来的测量数据显示出的气候上的变化

全球变暖：地球大气层和海洋的整体温度逐渐升高，通常归因于温室效应的家居

温室效应：一种自然过程，来自地球大气层的辐射，使地球气温高于在没有大气层情况下的问题。
